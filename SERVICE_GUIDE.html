🛠️ FaceTrack Service Management Guide

راهنمای مدیریت و پشتیبانی سرویس مانیتورینگ چهره و شیفت پرسنل در سرور ویندوز

📂 Project Location: C:\face_detection

⚙️ Windows Service Name: FaceTrack (FaceTrack Monitoring Service)

🌐 Dashboard URL: http://localhost:5173

🔧 Wrapper Executable: facetrack-service.exe (WinSW)

🚀 Quick Command Reference

Open PowerShell or Command Prompt as Administrator and navigate to the project directory:

cd C:\face_detection
Action WinSW Command Native PowerShell Alternative
Check Status .\facetrack-service.exe status Get-Service FaceTrack
Start Service .\facetrack-service.exe start Start-Service FaceTrack
Stop Service .\facetrack-service.exe stop Stop-Service FaceTrack
Restart Service .\facetrack-service.exe restart Restart-Service FaceTrack

🔄 Full Reinstall Cycle (If XML Configuration Changed)

If modifications were made to facetrack-service.xml (e.g. changing ports or arguments):

cd C:\face_detection
.\facetrack-service.exe stop
.\facetrack-service.exe uninstall
.\facetrack-service.exe install
.\facetrack-service.exe start

📋 Monitoring & Log Files

Logs automatically rotate at 10 MB and preserve up to 5 archive backups.

  • Standard Log (Detections & Events): C:\face_detection\facetrack-service.out.log
  • Error Log (Exceptions & Warnings): C:\face_detection\facetrack-service.err.log
  • Wrapper Engine Log: C:\face_detection\facetrack-service.wrapper.log

Live Log Streaming (Real-Time Output)

Get-Content C:\face_detection\facetrack-service.out.log -Tail 50 -Wait

Error Log Streaming

Get-Content C:\face_detection\facetrack-service.err.log -Tail 50 -Wait

🔒 Crucial Rules (Data Preservation)

1. DO NOT DELETE OR OVERWRITE C:\face_detection\data\`:

Contains face_tracking.db (all people, registered faces, shift records, system logs). Deleting it will wipe out system data!

2. DO NOT DELETE C:\face_detection\venv\`:

Contains the server's Python virtual environment and offline dependencies.

🩺 Troubleshooting

1. Port Conflict (WinError 10048 or WinError 10013)

If port 5173 is occupied by another process or an orphaned Python task:

Stop-Process -Name python -Force
C:\face_detection\venv\Scripts\python.exe -c "import socket; s = socket.socket(); s.bind(('0.0.0.0', 5173)); s.close(); print('Port 5173 is free!')"
.\facetrack-service.exe start

2. Allow Port in Firewall

If client computers cannot access the web dashboard on port 5173:

New-NetFirewallRule -DisplayName "FaceTrack Web Dashboard" -Direction Inbound -LocalPort 5173 -Protocol TCP -Action Allow

3. Windows Services Graphical Manager

Press Win + R → type services.msc → locate FaceTrack Monitoring Service.
